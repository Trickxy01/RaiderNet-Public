# Privacy Policy - RaiderNet

**Last Updated:** September 2026

## 1. Data We Collect
RaiderNet only processes data necessary for its core operational features[cite: 1]. This may include:
* Discord User IDs and Usernames
* Discord Server (Guild) IDs and Role IDs
* Command usage logs for performance and error tracking

## 2. How We Use Data
Collected data is strictly used to maintain bot functionality, render server rosters, track operational command structures, and enforce permissions[cite: 1]. We do **not** sell, share, or monetize any user data.

## 3. Data Retention & Removal
Data is stored only as long as necessary to provide service to your server. If RaiderNet is removed from a server, stored server-specific configuration data will be deleted upon request or routine cleanup.

## 4. Contact
If you have questions about this policy or wish to request data removal, contact the bot owner via the official RaiderNet Discord server.
